# Process evidence

This directory is the human↔AI process trail:

- `DECISIONS.md` — engineering decisions made during the build, each with the
  alternative that was rejected and why.
- `AI_WORKLOG.md` — dated notes of real events while building with a coding
  agent: suggestions accepted/rejected, observed failures, fixes, eval
  additions. Written as things happen, not reconstructed afterwards.
- `selected_sessions/` — a small number of exported coding-agent conversation
  excerpts showing suggestion → disagreement → reasoning → resolution.
  Volume is not signal; only moments that changed an outcome belong here.

Nothing in these files is fabricated or retroactively authored. Entries are
added when the event happens.
